# Spotify Clone (HTML + CSS)

A responsive front-end clone of Spotify built using only HTML and CSS. This project focuses on replicating the design and layout of the original Spotify web app.

# Features

- Pixel-perfect UI inspired by Spotify
- Fully responsive design (mobile, tablet, desktop)
-  Styled player section
- Sidebar navigation
- Album/playlist cards and hover effects

# Tech Stack

- HTML5
- CSS
- Flexbox
- Responsive Media Queries
- Google Fonts / Icons
